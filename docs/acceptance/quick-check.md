# Quick Check 驗收清單

## 主流程
1. 打開頁面 → 看到標題和說明，沒有任何 ⓘ 提示
2. Planned 輸入 120 → 結果區還沒出現數字（Available 還沒填）
3. Available 輸入 90 → 出現可安排時間、差距、假設清單
4. 看到兩張調整卡片 → 說得出「縮短」和「移到明天」的差別
5. 按 Halve time → Available 變成 45，結果立刻更新
6. 按 30 min less → Available 變成 15，結果立刻更新
7. Planned 輸入 99999 → 出現溫和提示，畫面沒壞
8. 按 Reset → 回到初始狀態，游標回到 Planned

## 鍵盤
- [ ] Tab 順序：Planned → Available → Halve → 30 min less → Reset
- [ ] Enter 和空白鍵都能按下按鈕
- [ ] 焦點框看得清楚

## 手機（375px）

- [ ] 按鈕好按（至少 44px 高）
